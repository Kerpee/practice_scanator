## Описание

Программа предназначена для обнаружения крестообразных маркеров на изображениях. Поддерживает два режима работы:

- **GRID** - анализ сетки маркеров с восстановлением координат
- **SINGLE** - поиск одиночного крестика

## Требования

- Python 3.8 или выше
- OpenCV 4.5+
- NumPy
- Pillow (для GUI)
- Matplotlib (опционально)

## Конфигурация

### Параметры конфигурации

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| grid_rows | Количество строк в сетке | 7 |
| grid_cols | Количество столбцов в сетке | 7 |
| marker_step_mm | Шаг между маркерами в мм | 35.0 |
| pca_roi_size | Размер области интереса для PCA | 15 |
| pca_corner_ratio | Коэффициент для обнаружения углов | 0.12 |
| cluster_dist | Расстояние кластеризации | 80.0 |
| angle_thresh | Порог угла в градусах | 25.0 |
| show_images | Показывать изображения | true |
| show_statistics | Показывать статистику | true |
| show_coordinate_systems | Показывать координатные системы | true |
| verbose | Подробный вывод | false |
| debug | Режим отладки | false |
| start_image | Начальный номер изображения | 1 |
| end_image | Конечный номер изображения | 10 |
| cross_mode | Режим работы (grid/single) | grid |
| save_images | Сохранять изображения | false |
| save_coords | Сохранять координаты | false |
| output_dir | Папка для результатов | output |

### Файл конфигурации (config.json)

\```json
{
  "grid_rows": 7,
  "grid_cols": 7,
  "marker_step_mm": 35.0,
  "pca_roi_size": 15,
  "pca_corner_ratio": 0.12,
  "cluster_dist": 80.0,
  "angle_thresh": 25.0,
  "show_images": true,
  "show_statistics": true,
  "show_coordinate_systems": true,
  "verbose": false,
  "debug": false,
  "start_image": 1,
  "end_image": 10,
  "cross_mode": "grid",
  "save_images": false,
  "save_coords": false,
  "output_dir": "output"
}
\```

## Интерфейсы

### 1. Консольный интерфейс

Интерактивное меню с пунктами:

\```
ГЛАВНОЕ МЕНЮ
----------------------------------------------------------------------
  1 - Запустить обработку
  2 - Редактировать конфигурацию
  3 - Загрузить конфигурацию из JSON

### 2. Графический интерфейс

При запуске с параметром `--gui` открывается окно с настройками:

- Левая панель: все параметры конфигурации
- Правая панель: отображение результатов
- Кнопка "ЗАПУСТИТЬ ОБРАБОТКУ" для старта
- Кнопка "Следующий кадр" для пошагового просмотра

| Аргумент | Описание |
|----------|----------|
| --fast | Быстрый запуск без отображения изображений |
| --no-ui | Запуск без интерфейса |
| --gui | Запуск графического интерфейса |
| --config | Путь к JSON файлу конфигурации |
| --output-dir | Папка для сохранения результатов |
| --save-images | Сохранять обработанные изображения |
| --save-coords | Сохранять координаты точек |

## Сохранение результатов

### Структура папок

При включенном сохранении (`--save-images` и/или `--save-coords`) создается следующая структура:

\```
output/                          # Корневая папка результатов
├── images/                      # Сохраненные изображения
│   ├── grid_1.jpg              # Результат для кадра 1 (режим GRID)
│   ├── grid_2.jpg              # Результат для кадра 2
│   └── single_1.jpg            # Результат для кадра 1 (режим SINGLE)
└── coordinates/                 # Сохраненные координаты
    ├── coordinates_1.csv       # Координаты для кадра 1
    ├── coordinates_2.csv       # Координаты для кадра 2
    └── all_results.json        # Все результаты в одном файле
\```

### Формат CSV файла

\```csv
Image,Point_Type,ID,X,Y
1,grid_point,0,100.5,200.3
1,grid_point,1,135.7,200.1
1,origin,0,100.5,200.3
1,x_axis,0,135.7,200.1
1,y_axis,0,100.5,235.9
\```

### Формат JSON файла

\```json
{
  "image": "1",
  "mode": "grid",
  "timestamp": "2024-01-15 14:30:25",
  "grid_size": [7, 7],
  "points_found": 49,
  "points": [[x1, y1], [x2, y2], ...],
  "coordinate_systems": [
    {
      "origin": [x, y],
      "x_axis": [x, y],
      "y_axis": [x, y]
    }
  ],
  "processing_time": 0.456
}
\```

## Устранение неполадок

### Ошибка: "Не удалось открыть изображение"

**Решение:**
- Поместите изображения в папку `data/`
- Используйте имена файлов: `1.jpg`, `2.jpg`, `3.jpg`, ...
- Проверьте расширение файла


### Производительность

Для улучшения производительности:
- Используйте `--fast` для отключения визуализации
- Уменьшите диапазон обрабатываемых изображений
- Используйте изображения меньшего размера
