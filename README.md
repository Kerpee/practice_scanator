# Scanner Calibration ML Detector

Этот проект предназначен для автоматического поиска калибровочных крестов на сканированных документах. Алгоритм использует гибридный подход:
1. Нейросеть **YOLOv8** находит рамки вокруг крестиков с высокой точностью. Мы используем оригинальное разрешение изображения, а также умный фильтр для ранжирования найденных крестов по уверенности (берется строго топ-49 лучших результатов).
2. Алгоритм **Компьютерного зрения (OpenCV Moments)** находит субпиксельный центр масс внутри рамки, предоставленной YOLO.

Это дает практически идеальные 49 из 49 меток на любых фотографиях!

## Запуск скрипта

1. Для массовой обработки фотографий (или одиночной) используйте скрипт `cli.py`.
2. Укажите путь к папке с фотографиями (`--input`) и папку для сохранения результатов (`--output`).
3. Скрипт автоматически создаст папку с датой и временем внутри `output` и сохранит туда размеченные фотографии и CSV файлы.

```bash
cd ML
python cli.py --input ../data/ --output results/
```

## Требования

Скрипт требует установленных библиотек:
- `ultralytics` (для YOLOv8)
- `opencv-python` (для работы с изображениями)
- `scikit-learn` (использовалось для DBSCAN)

Установить их можно так:
```bash
pip install ultralytics opencv-python scikit-learn
```

## Структура файлов
- `cli.py` — интерфейс командной строки.
- `mlka.py` — ядро алгоритма (`ScannerCalibrationApp`).
- `model.pt` — обученные веса YOLOv8, оптимизированные для поиска крестов.
